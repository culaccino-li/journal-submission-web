# Journal Submission Guides

Public-facing journal submission guides for researchers preparing academic manuscripts.

The site explains what each journal usually expects, what topics fit, how manuscripts should be framed, and where authors are most likely to face reviewer objections.

## Pages

- `index.html`: guide library homepage
- `pages/scientometrics.html`: Scientometrics submission guide
- `data/journals.json`: structured journal index
- `assets/styles.css`: site styles

## Publishing

This is a static website. It can be published with GitHub Pages from the repository root.
